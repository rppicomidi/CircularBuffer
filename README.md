# CircularBuffer template class
The C++ template class implements a circular buffer of a fixed size.
The template was adapted from the CircularBuffer template class
from wikipedia. See the LICENSE file for more information.

The example directory contains test_CircularBuffer.cpp, a short program
designed to exercise all of the functions in the template class. It also
contains a union class that demonstrates how you might use a circular
buffer that contains USB MIDI 1.0 packets.
